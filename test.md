
# Информация по Git 

## Краткое пособие по командам
>**git init** инициализация проекта;

>**git add имя файлы**  добавления файловм в систему для отслеживания.

>**git add .** добовления всех файлом

>**git commit -m "Added fails"** добовление коммита

>**git commit -am "Added fails"** добовление коммита И одновременно добваалние файлолм (Пользоваться очеь осторожно можно добавить все подряд)

>**git log** просмотр всех сомитов и логов в истории

>**git checkout номер хеша можно 5-6 симфолов** перемещение по симтории коммитов или откат до той версии , которая нам нужна;

>**git checkout main/master** в зависимости от названия главной ветки, возвращение к последнему камиту
